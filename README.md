# Receipt Tracker

Веб-приложение для сканирования чеков, автоматического распознавания покупок и анализа расходов.

Пользователь фотографирует чек, приложение распознаёт позиции и суммы, пользователь проверяет
и исправляет результат, данные попадают в историю и аналитику расходов.

## Статус

Проверка гипотезы. Разработка не начата — на текущий момент в репозитории только документация.

Ближайшая задача — [M0: spike точности распознавания](docs/BACKLOG.md). До того как писать приложение,
нужно измерить, распознаются ли реальные чеки достаточно хорошо, чтобы продуктом имело смысл пользоваться.

## Стек

Nuxt 4 (SPA) + Vue 3 + TypeScript на фронте, NestJS + Prisma + PostgreSQL на бэке,
BullMQ поверх Redis для асинхронной обработки, S3-совместимое хранилище для изображений.
Подробности и обоснование — в [PROJECT_PLAN.md](docs/PROJECT_PLAN.md) и [adr/](docs/adr/).

## Стоимость

На этапе проверки гипотезы — 0. Вся инфраструктура поднимается локально в Docker,
распознавание работает на бесплатных моделях OpenRouter. Подробности в
[ADR-0011](docs/adr/0011-free-tier-first.md).
