# ADR-0011 — Бесплатные модели на этапе проверки гипотезы

**Статус:** принято
**Дата:** 2026-08-30

## Контекст

Проект проверяет гипотезу и может не дойти до продукта. Платить за инфраструктуру
до того, как гипотеза подтверждена, незачем. При этом объём смехотворный —
порядка сотни чеков в месяц, — так что бесплатных лимитов хватает с запасом.

Отдельное соображение: часть провайдеров OCR требует привязки банковской карты
даже для бесплатного тарифа. Vision-модель через OpenRouter карты не требует
вообще, и она же может заменить OCR целиком — читая изображение напрямую
и возвращая структурированный ответ одним вызовом.

## Решение

На этапе проверки гипотезы стоимость проекта — ноль.

| Компонент                | Решение                    | Лимит                    |
| ------------------------ | -------------------------- | ------------------------ |
| Распознавание            | OpenRouter, модели `:free` | 20 запросов/мин, 50/день |
| PostgreSQL, Redis, MinIO | Docker локально            | —                        |
| Ошибки                   | Структурные логи (pino)    | —                        |
| CI                       | GitHub Actions             | 2000 мин/мес             |

Обращение к OpenRouter — через OpenAI SDK с подменённым `baseURL`, поскольку
API совместимо.

### Что учтено в реализации

Список бесплатных моделей ротируется: модель может исчезнуть, вернув `404`,
или упереться в лимит провайдера, вернув `429`. Поэтому конфигурация задаёт
не одну модель, а упорядоченный список кандидатов с переходом к следующему
при отказе. Это не гипотетическая проблема — ровно такое поведение наблюдалось
в другом проекте на том же провайдере.

Лимит в 50 запросов в день мал не для использования (три чека в день — норма),
а для отладки промпта, где один чек прогоняется десятки раз. Смягчается
кэшированием ответов по хешу файла и локальным набором сохранённых результатов
для офлайн-итераций. Разовая покупка кредитов на $10 поднимает дневной лимит
до 1000 навсегда, если станет тесно.

## Альтернативы

**Google Cloud Vision** — 1000 распознаваний в месяц бесплатно постоянно,
но требует карту и даёт только текст, без структуры.

**Azure Document Intelligence F0** — 500 страниц в месяц с готовой моделью
для чеков. Ограничение «первые две страницы документа», из-за которого этот
тариф обычно ругают, для чеков не значит ничего — чек одностраничный.
Требует карту. Остаётся эталоном качества в M0.

**Платный провайдер сразу** — при таком объёме речь о единицах долларов
в месяц, но нет причин платить, пока гипотеза не подтверждена.

## Последствия

Разработка и проверка гипотезы ничего не стоят. Ограничение частоты запросов
приходится учитывать в коде — но это полезно, поскольку понадобится и на платном
тарифе.

Важное следствие для персональных данных: бесплатные endpoint'ы могут обучаться
на запросах. Пока обрабатываются собственные чеки — это осознанное решение
о своих данных. Условия перехода описаны в [ADR-0012](0012-deferred-privacy-posture.md).

## Когда пересмотреть

Перед первым внешним пользователем — обязательно, см. ADR-0012.
Раньше — если бесплатные модели окажутся недостаточно точными в M0; тогда
стоимость точного распознавания становится частью ответа на вопрос
о жизнеспособности продукта.
