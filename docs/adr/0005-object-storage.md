# ADR-0005 — Изображения в object storage

**Статус:** принято
**Дата:** 2026-08-30

## Контекст

Каждый чек — изображение размером в единицы мегабайт. Их нужно хранить,
отдавать в интерфейс и удалять вместе с чеком.

## Решение

Файлы в S3-совместимом хранилище: MinIO локально, Cloudflare R2 в production.
В БД — только ключ объекта и метаданные.

Изображения никогда не публичны. Интерфейс получает подписанные ссылки
с ограниченным временем жизни.

Хранятся два варианта: оригинал и уменьшенная копия для списков. Отдавать
многомегабайтный оригинал в списке чеков нельзя.

## Альтернативы

**BYTEA в PostgreSQL** раздувает базу, замедляет резервное копирование
и заставляет гонять бинарные данные через слой ORM.

**Локальная файловая система** не переживает пересоздание контейнера
и не масштабируется на несколько экземпляров.

R2 выбран вместо S3 из-за отсутствия платы за исходящий трафик — при просмотре
истории чеков изображения отдаются часто.

## Последствия

База остаётся компактной. Раздача изображений не нагружает Node.js.
Локальная разработка использует тот же протокол, что и production.

Плата — удаление становится операцией в двух системах. Требуется явная
процедура очистки объектов, потерявших владельца.

## Когда пересмотреть

Не пересматривать.
